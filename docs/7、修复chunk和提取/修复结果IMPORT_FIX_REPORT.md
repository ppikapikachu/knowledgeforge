# 知识导入链路排查与修复交付报告

## 一、问题根因

| 问题 | 根因 | 位置 |
|------|------|------|
| 86 个碎片 Chunk | TXT 解析按 `\n\n` 切成 86 个"页面"，每页 < 6000 直接成 Chunk，**无短块合并** | `chunker.py` 的 `chunk()` 方法 |
| 提取内容虚假 | Prompt 未强制保留原文、防幻觉约束弱 | `prompts.py` 的 `SYSTEM_PROMPT` |
| 同名重复 | 批次去重仅按名称精确匹配，同名不同内容未处理 | `batch_dedup.py` |
| 15 分钟 | 86 个 Chunk × 逐个 LLM 调用 = 86+ 次请求 | 分块碎片化的连锁反应 |

## 四、修复策略

### 4.1 分块（Q&A 结构感知）

```
识别顶层题目编号（1、2、3.）→ 区分答案内子项（1）2））
→ 题目+所有答案归为同一逻辑块
→ 多个逻辑块聚合到 chunk_size=6000
→ 短块合并 + 最小长度保护（< 50 字符合并）
```

### 4.2 提取 Prompt v2

- **content 必须完整保留源文细节**（方法列表、解释、条件、例子）
- **禁止新增原文没有的内容**（如"横竖屏切换"、"ViewModel"）
- **无答案题目跳过**，不生成占位知识点

### 4.3 批次去重

- 标准化名称相同 → 必定重复，保留内容更完整的版本
- 同名但内容差异 > 50% → 标记冲突，保留先出现的
